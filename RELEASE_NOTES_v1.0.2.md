# Halloween Theme v1.0.2 — Ghost Audio Rotation Fix

**Beat Saber 1.40.8_7379 (Meta Quest)**

This patch incorporates the headset-tested audio improvements from the v1.0.1 correction branch.

- Approximately **42% of spawned ghosts produce a vocal sound**, leaving the remainder silent.
- Five approved ghost recordings rotate through a randomized **shuffle bag**. Each available clip plays once per cycle before repeating, with no immediately repeated clip between cycles when more than one clip is loaded.
- Retains Halloween ghost celebrations exclusively for **S, SS, and SSS** ranks, twelve approved ghost designs (including the shy ghost), randomized drift, fading, balanced spawning, and automatic cleanup on results exit.
- Removes obsolete `assets/ghost_particle.png` from the source repository.
- **Preserves `Cover.png`** for the MBF listing, `Halloween-Banner.png` for the QMOD, and `Halloween-README.png` for GitHub.
- Includes all five audio files and their OpenGameArt/Pixabay credits in the QMOD.

**Compatibility:** Scotland2 Beat Saber Quest 1.40.8_7379. Install `Halloween-Theme.qmod` through QuestPatcher/MBF as appropriate. Do not install conflicting standalone seasonal themes alongside the Holiday Theme Switcher.

**Licensing:** Third-party sound credits and license notices are preserved in `GHOST_AUDIO_CREDITS.txt` and `PIXABAY_AUDIO_CREDITS.txt`. A prior request for written Pixabay clarification about extractable audio remains open.

This is a new immutable patch release: v1.0.1 remains available, and the exact v1.0.2 QMOD is built from matching v1.0.2 source.
